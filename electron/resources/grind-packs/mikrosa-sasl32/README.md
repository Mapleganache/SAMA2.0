# MIKROSA SASL32 磨削宏包（砂轮侧 GW PROGRAM）

现场来源：`桌面/米克罗莎SASL32/GW PROGRAM`。SAMA 出码时调用这些程序号，不把无心磨改写成外圆 ISO 纵磨。

| 程序 | 作用 |
|------|------|
| O1111 | 修整廓形数据 `#640`/`#680` |
| O8200 | 砂轮预置 GW PRESET |
| O8201 | 砂轮修整 GW DRESS |
| O8204 | 磨削预置 |
| O8205 | 磨削运行（Y`#540` 分段切入） |
| O8400 | 导轮转速 |
| O8500 / O8501 / O8503 | 磨削回零 / 修整回零 / 全回零 |
| O8600 / O8601 / O8602 | 补偿 |

导轮侧在同级目录的 `RW PROGRAM`（O8202/O8203 等）。下机床前以本机画面当前 `#540` 为准。
