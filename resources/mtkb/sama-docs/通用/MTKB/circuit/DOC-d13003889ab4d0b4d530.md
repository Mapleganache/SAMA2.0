## 阅读方法

1. 扫描顺序：LEVEL1 -> LEVEL2 -> 依次执行 P1~P6。
2. 每个网络：先看「作用」，再看指令表。
3. 地址：X输入、Y输出、G发CNC、F来自CNC、R内部、K保持、A报警、D数据、P子程序。

## 程序结构

| 程序 | 名称 | 作用 |
|------|------|------|
| LEVEL1 | 高速级 | 急停、轴联锁/机床锁 |
| LEVEL2 | 第二级 | 调用 P1~P6 |
| P1 | SYSTEM SET | 系统设定：模式、手轮、启停等 |
| P2 | MACHINE LOGIC | 机床逻辑：润滑/冷却/砂轮等 |
| P3 | C CONTROL | C轴相关控制 |
| P4 | OVERRIDE CONTROL | 进给/快速/手轮倍率 |
| P5 | OTHER | 其他辅助逻辑 |
| P6 | ALARM DISPLAY | 报警显示与复位 |
