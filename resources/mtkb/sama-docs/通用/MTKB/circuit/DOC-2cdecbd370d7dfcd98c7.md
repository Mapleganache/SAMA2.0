## 手轮选轴程序（地址版 · 白话）

> 对应 `studer_梯形图说明书.md` 里 **P1 · N00011～N00016、N00047**  
> 本页**只用地址**讲，尽量不靠容易误导的符号名。  
> （符号名里 Z/C 和真实按键对不上，看地址更不容易晕。）

---

## 面板按键（输入）

| 地址 | 面板上一般是 |
|------|----------------|
| **X7.3** | 选手轮 **X** 轴 |
| **X7.5** | 选手轮 **Z** 轴 |
| **X7.6** | 选手轮 **C** 轴 |
| **F0.7** | CNC「正在自动运行」（为 1 时不允许选 Z/C 手轮） |

## 中间记忆（程序内部先记一笔）

| 地址 | 程序里实际当什么用（按最终动轴理解） |
|------|--------------------------------------|
| **R25.0** | 「选了 X」的记忆 |
| **R25.1** | 名字像 Z，但**实际是按 C 键时点亮** |
| **R25.2** | 名字像 C，但**实际是按 Z 键时点亮** |

## 交给 CNC 的两根线（输出）

| 地址 | 作用 |
|------|------|
| **G18.0** | 手轮轴选择码 第1位 |
| **G18.1** | 手轮轴选择码 第2位 |

CNC 常见看法（本机 X/Z/C）：

| G18.0 | G18.1 | 动哪轴 |
|-------|-------|--------|
| 亮 | 灭 | **X** |
| 灭 | 亮 | **Z** |
| 亮 | 亮 | **C** |
| 灭 | 灭 | 没选手轮轴 |

## 旁边两个小输出

| 地址 | 作用 |
|------|------|
| **R700.1** | 「手轮模式」内部标志（选了 Z 或 C 相关记忆就亮） |
| **Y6.6** | 面板上手轮指示灯 |

---

## N00011：记住「选了 X」

- 条件：按下 **X7.3**，同时 **X7.6、X7.5** 都没按  
- 结果：点亮 **R25.0**

→ 按 X，就记在 R25.0。这一步是正常的。

---

## N00012：本想记 C，实际在认 Z 键

- 条件：**X7.6 没按**、**X7.3 没按**、**X7.5 按下**，并且 **F0.7 不是自动**  
- 结果：点亮 **R25.2**

→ 你按的是 **Z（X7.5）**，程序却去点 **R25.2**。

---

## N00013：本想记 Z，实际在认 C 键

- 条件：**X7.5 没按**、**X7.3 没按**、**X7.6 按下**，并且 **F0.7 不是自动**  
- 结果：点亮 **R25.1**

→ 你按的是 **C（X7.6）**，程序却去点 **R25.1**。

**第一步小结（按键 → 记忆）：**

| 你按 | 点亮的地址 |
|------|------------|
| X7.3 | R25.0 |
| X7.5（Z） | **R25.2** |
| X7.6（C） | **R25.1** |

---

## N00014：决定 G18.0 亮不亮

程序看三个记忆，规则用白话说：

- **R25.0 亮了，或者 R25.1 亮了**  
- **并且 R25.2 没亮**  
- → 就点亮 **G18.0**

为什么「两个里有一个就行，再排除第三个」？  
因为 G18.0 要在「选 X」和「那种两灯都亮的选法」里都会亮；选「只亮 R25.2」那种时，G18.0 必须灭。

---

## N00015：决定 G18.1 亮不亮

- **R25.2 亮了，或者 R25.1 亮了**  
- **并且 R25.0 没亮**  
- → 就点亮 **G18.1**

**第二步小结（记忆 → 两根线）：**

| 哪个记忆亮 | G18.0 | G18.1 | CNC 会动 |
|------------|-------|-------|----------|
| 只有 R25.0 | 亮 | 灭 | X |
| 只有 R25.1 | 亮 | 亮 | C |
| 只有 R25.2 | 灭 | 亮 | Z |

---

## N00047：要不要进「手轮模式」标志

- **R25.1 或 R25.2** 任一亮 → 点亮 **R700.1**  
- 所以你按物理 Z 或 C，这个标志都会亮（中间记错名字也不耽误）。

## N00016：面板灯

- **R700.1 亮，或者 R25.0 亮** → 点亮 **Y6.6**（手轮灯）

---

## 按 X（X7.3）

1. N00011 → **R25.0** 亮  
2. N00014 → **G18.0** 亮；N00015 → **G18.1** 灭  
3. CNC 看到「亮、灭」→ 动 **X**  
4. N00016 → **Y6.6** 亮

## 按 Z（X7.5）

1. N00012 → **R25.2** 亮（中间记岔了）  
2. N00014 → G18.0 灭；N00015 → **G18.1** 亮  
3. CNC 看到「灭、亮」→ 动 **Z**（又对回来了）  
4. N00047 → **R700.1** 亮；N00016 → **Y6.6** 亮

## 按 C（X7.6）

1. N00013 → **R25.1** 亮（中间记岔了）  
2. N00014 → **G18.0** 亮；N00015 → **G18.1** 亮  
3. CNC 看到「亮、亮」→ 动 **C**（又对回来了）  
4. N00047 → **R700.1** 亮；N00016 → **Y6.6** 亮  

---

## 一句话

**按键地址（X7.3/5/6）→ 记到 R25.0/1/2（Z/C 记反）→ 编成 G18.0/G18.1 → CNC 按两根线动轴。**  
中间记反了一次，编码相对名字又反了一次，所以现场往往还能按对轴；看程序请盯地址，别盯符号名。

## 若你指的是 FANUC 软件/机床画面「符号 ⇄ 地址」切换

那是显示方式，不是改程序：

- **FANUC Ladder 编辑软件**：梯形图画面软键或菜单里找 **Address / Symbol**（地址 / 符号）切换。  
- **机床 PMC 梯形图画面**：常见在梯图显示页用软键 **地址 / 符号** 切换触点上显示的内容。
