## 位置

| 项 | 内容 |
|----|------|
| 程序 | LEVEL1 |
| 网络 | **N00002** |
| 说明书 | **489 ~ 498 行** |
| 地址 | `X9.5`、`R9091.1` → `G116.0`、`G114.0` |

## 现有逻辑

```
(X9.5 通)  或  (R9091.1 通)
    → 同时写 G116.0（负超程）和 G114.0（正超程）
```

因为常1永远通，整网结果**几乎永远为通**。

## 问题是什么

1. 常1并联 = 软件超程保护被旁路掉。  
2. 正负用同一条件同写，CNC 分不清撞哪一侧。

## 会造成什么

X1 撞限位时，PMC 侧 `*+L/*-L` 仍可能一直处于「允许」态（负逻辑下常1写出），超程保护失效；诊断也无方向信息。

## 怎么改 / 改成什么样

```
【删除】并联常开 R9091.1

【正负分写】（以电气图为准，示意）
  X1-限位 → 只写 G116.0
  X1+限位 → 只写 G114.0
  不要同一线圈条件写两个方向
```

若调试需要旁路：用独立钥匙 K + 限时 + 报警灯，**禁止**用常1。

## 位置

| 项 | 内容 |
|----|------|
| 程序 | P2 |
| 网络 | **N00154** 机床就绪辅助2 |
| 说明书 | **2539 ~ 2552 行** |
| 地址 | `X8.3`（副急停）、`R9091.1`、`X8.4`、`X8.5`、`R3500.2` |

## 现有逻辑（按指令表）

就绪自保大致为：

```
(启动条件 ∨ R3500.2) ∧ X8.4 ∧ X8.5 ∧ (X8.3 ∨ R9091.1)
→ 写 R3500.2
```

`X8.3 ∨ R9091.1` 因常1永远为真 → **副急停不起作用**。

## 问题是什么

副急停按钮被焊死为「永远满足」。

## 会造成什么

按副急停无法拆掉就绪；操作者以为有双急停，实际只有主急停等在卡。

## 怎么改 / 改成什么样

```
【删除】并联常开 R9091.1

改后：
  … ∧ X8.4 ∧ X8.5 ∧ X8.3  →  R3500.2

验收：断开 X8.3（或按副急停使输入为断）→ R3500.2 掉、伺服掉
```

## 位置

| 项 | 内容 |
|----|------|
| 程序 | LEVEL1 ← 依赖 P2 |
| 网络 | **N00001**；就绪链 **N00154 → N00155** |
| 说明书 | N00001：**465 ~ 487**；N00155：**2554 ~ 2562** |
| 地址 | LEVEL1 读 `R710.0` 写 `G8.4`/`G1008.4`…；`R710.0`←`R3500.2`（含 `X8.4`） |

## 现有逻辑

```
硬件急停 X8.4  →（在 P2）→ R3500.2 → R710.0
LEVEL1：R710.0 → G8.4（*ESP）、G8.0、双路径联锁/机床锁…
```

高速级**不直接读** `X8.4`。

## 问题是什么

急停要先经过第二级就绪逻辑，再反映到第一级 `*ESP`，响应路径长、依赖多。

## 会造成什么

急停到 NC 侧联锁的实时性变差；就绪链任一异常都可能扭曲急停行为。

## 怎么改 / 改成什么样

```
【LEVEL1 N00001 目标】
  直接：X8.4（及必要的硬件安全条件）
  → 写 G8.4 / G1008.4 / G8.0 / G1008.0 / G130.* / G1130.* …

【就绪 R710.0】
  仍由 P2 管伺服 Y4.4 等
  但不要用「就绪」替代「急停」去驱动 *ESP
```

## 位置

| 项 | 内容 |
|----|------|
| 程序 | P1 |
| 网络 | **N00123** |
| 说明书 | 约 **2161 ~ 2171 行** |
| 地址 | `R9091.1` → `G29.4`、`G29.6`、`G1029.4`、`G1029.6` |

## 现有逻辑

常1一通就写 SAR（主轴速度到达）和 `*SSTP`（主轴停止互锁）以及路径2 对应位。

## 问题是什么

真实主轴反馈不再决定这些信号，联锁被空通过。

## 会造成什么

主轴未达速也可能被当成「已到达」；停止互锁可能一直假允许。

## 怎么改 / 改成什么样

```
G29.4  SAR   ← 真实主轴达速反馈（F 或 X，以电气为准）
G29.6  *SSTP ← 急停/报警/M05/需要停主轴时的条件
路径2 G1029.* 同理
禁止：R9091.1 直接 WRT 这些位
```

---

## 位置

全书检索：无门/罩开关进入 Cycle Start 禁止或掉 `Y4.4` 的完整链。

## 问题与后果

若电气也未做安全门回路，则开门可运行；若硬件已有安全继电器，PMC 仍缺一层联锁与提示。

## 怎么改 / 改成什么样

```
1. 现场确认：安全门是否已进安全继电器
2. 若未进 PMC：增加门输入 X
   → 门开：禁止写循环启动 G；A 类报警；必要时清 R3500.2 / 关 Y4.4
3. 自动模式强制门关
```

## 现有逻辑

| 网络 | 按键 | 模式条件 | 输出 |
|------|------|----------|------|
| N00088 Z2− | X10.7 | **F1003.2**（路径2 JOG）∨ F1004.5 | G1102.2 |
| N00089 Z2+ | X10.1 | **F3.2**（路径1 JOG）∨ F4.5 | G1100.2 |

## 问题是什么

Z2+ 点动看的是**路径1**的 JOG 确认位，和对称网不一致。

## 会造成什么

路径2 点动 +Z 时：可能在路径1 才是 JOG 时才动，或路径2 JOG 时反而不动——双路径操作混乱。

## 怎么改 / 改成什么样

```
【N00089 改成与 N00088 对称】

改前：
  X10.1 ∧ (F3.2 ∨ F4.5) → G1100.2

改后：
  X10.1 ∧ (F1003.2 ∨ F1004.5) → G1100.2
```

验收：仅路径2 为 JOG（或对应回零）时，Z2± 都有效。

## 位置

例如 **N00386** AIR ERROR（约 5280 行）：条件含 `¬R9091.1`；同类还有若干 A1.x / A2.x

## 现有逻辑

要置报警，必须常1为**断**。但常1恒通 → **这些报警网永不置位**。

## 会造成什么

气源/相关故障灯可能永远不亮（死代码）；或常1异常为 0 时反而乱报警。

## 怎么改 / 改成什么样

```
删除条件里的「串联常闭 R9091.1」
AIR ERROR 应改为：
  就绪延时 ∧ ¬气压开关 ∧ ¬K旁路（若保留旁路）→ SET A0.5
变频器故障用单独 A 位，不要和气源混在一个条件里
```

## 问题是什么（注释层面）

说明书把部分 X 写成「参考点」、部分写成「限位」。**从地址无法证明接错**，只能对照电气图。

另：Y 轴路径1/2 的正负 G 极性相对对调（结构性疑点），可能是故意接线，也可能是拷贝错误——**现场核实**。

## 怎么改 / 改成什么样

1. 电气图标注每个 X 是 OT 还是 DEC/参考点。  
2. 若是参考点误进 OT：改接到真实限位，或改为减速逻辑，不要驱动 `*L`。  
3. 同步改符号注释，与实物一致。  
4. **在核实前，不要仅因注释文字就改 G 映射。**

## 第三部分：修改优先级与验收

| 顺序 | 改什么 | 改成什么样（验收） |
|------|--------|--------------------|
| 1 | A-H01/H02 去常1、正负分写 | 撞 X 限位时 CNC 报对应方向超程 |
| 2 | A-H03 副急停 | 断 X8.3 → 就绪与伺服掉 |
| 3 | A-H05 SAR/*SSTP | 随真实主轴变化，非常亮 |
| 4 | A-H04 *ESP 直连 | LEVEL1 直接看 X8.4 |
| 5 | A-M01 N00089 | Z2± 都只用路径2 JOG 位 |
| 6 | A-M02 补 R25.5 | 选 Z2 手轮时自动下手轮逻辑成立 |
| 7 | A-M05/M06/M07/M08 | M 等真实完成；报警能亮且 A 类能停 |
| 8 | C01~C05 | 注释与电气一致；不误导改线 |

## 结论

米克罗莎**必须先改的地址问题**：X 轴超程常1旁路、副急停常1旁路、SAR/*SSTP 常1、急停间接化、Z2+ 模式位用错路径、报警死区与报警组漏项。  

「参考点」等字样先当**注释待核实**，对照电气图后再决定是否改 OT 接线逻辑；不要只凭注释改地址映射。
