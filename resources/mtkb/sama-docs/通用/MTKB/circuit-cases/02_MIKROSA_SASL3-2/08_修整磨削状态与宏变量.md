# MIKROSA SASL3/2：修整/磨削状态、回零和宏变量接口

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

## 1. 功能

处理砂轮/调节轮修整设定、磨削设定、回零状态以及 #1000 等宏变量接口。

- 案例编号：`CKB-MIKROSA-008`
- 机床：MIKROSA/FANUC SASL3/2
- 网络范围：N00208-N00240
- 实际收录网络：N00208  Interrupt signal for custom ma, N00209  INCH Y-, N00210  Y1 INCH- 1 L, N00211  INCH Y+, N00212  Y1 INCH+ 1 L, N00213  修整 (GW DRESS SET OK), N00214  R999.0, N00215  修整 (RW DRESS SET OK), N00216  R999.0, N00217  磨削 (GRIDING SET OK), N00218  R999.0, N00219  R999.0, N00220  R999.0, N00221  R999.0, N00222  修整 (GW DRESS HOME), N00223  修整 (RW DRESS HOME), N00224  磨削 (GRINDDING HOME), N00225  #1000, N00226  #1000, N00227  #1001, N00228  #1001, N00229  #1002, N00230  #1008, N00231  #1008, N00232  #1009, N00233  #1009, N00234  RO9I, N00235  R10I, N00236  R11I, N00237  R12I, N00238  SUB 8, N00239  #610--#612, N00240  SPE（子程序结束）
