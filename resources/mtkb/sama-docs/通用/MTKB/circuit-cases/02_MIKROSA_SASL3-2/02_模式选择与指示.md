# MIKROSA SASL3/2：自动/编辑/MDI/JOG/回零模式与指示

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

## 1. 功能

生成五种操作模式的辅助状态、CNC 模式编码和面板指示灯。

- 案例编号：`CKB-MIKROSA-002`
- 机床：MIKROSA/FANUC SASL3/2
- 网络范围：N00023-N00041
- 实际收录网络：N00023  自动模式K, N00024  编辑模式K, N00025  MDI模式K, N00026  JOG模式K, N00027  回零模式K, N00028  编辑模式辅助, N00029  自动模式辅助, N00030  JOG模式辅助, N00031  MDI模式辅助, N00032  回零模式辅助, N00033  编辑灯, N00034  自动灯, N00035  JOG灯, N00036  MDI灯, N00037  模式选择 MD1, N00038  自动下手轮, N00039  模式选择 MD2, N00040  模式选择 MD4, N00041  手轮灯

## 4. 故障诊断与核对点

- 验证模式编码不存在非法组合。
- 从自动切换到 JOG/回零时确认循环被安全保持。
- 面板灯只能作为状态提示，不能替代安全反馈。
