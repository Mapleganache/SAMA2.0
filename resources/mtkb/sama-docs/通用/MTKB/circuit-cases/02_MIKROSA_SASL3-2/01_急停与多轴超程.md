# MIKROSA SASL3/2：NC 急停与双通道多轴超程

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

## 1. 功能

处理 NC 急停以及 X1/Y1/Z1、X2/Y2/Z2 多轴正负超程，并完成 P1-P6 调度。

- 案例编号：`CKB-MIKROSA-001`
- 机床：MIKROSA/FANUC SASL3/2
- 网络范围：N00001-N00021
- 实际收录网络：N00001  NC侧急停, N00002  X1负超程, N00003  Y1正超程, N00004  Y1负超程, N00005  Z1正超程, N00006  Z1负超程, N00007  X2负超程, N00008  Y2负超程, N00009  Y2正超程, N00010  Z2负超程, N00011  Z2正超程, N00012  END1（第一级结束）, N00013  常0, N00014  常1, N00015  调用 P1 系统设定, N00016  调用 P2 机床逻辑, N00017  调用 P3 程序调用, N00018  调用 P4 倍率控制, N00019  调用 P5 宏处理, N00020  调用 P6 报警显示, N00021  END2（第二级结束）
