# 厂家官网核验与电路资料边界

## STUDER

- 官方服务/材料页面：<https://www.studer.com/en/customer-care/services/material/>
- 官网说明可为旧机床提供原厂备件，并提供服务、翻新和改造支持。
- 官网公开下载以产品和服务宣传资料为主，本次没有发现 S40-4 按序列号匹配的完整电气原理图公开下载。

## SCHAUDT / MIKROSA

- 官方页面：<https://www.schaudtmikrosa.com/en/>
- 官网明确说明仍提供 SCHAUDT 与 MIKROSA 的检查、维护、维修、备件和易损件服务。
- 本次没有发现 SASL3/2 完整电气图公开下载入口；旧机型资料应通过厂家服务渠道并按机床序列号索取。

## FAVRETTO

- 官方二手机床页面：<https://favretto.it/en/secondhand-machines/>
- 官网页面确认存在 FAVRETTO MC 160 N 水平磨头磨床（页面列为 Code 246）。
- 本次没有发现 MC160/MC 160 N 完整电气图公开下载入口。

## 使用结论

官网信息只用于核验品牌、机型和服务渠道，不能替代当前机床的原厂电气图。本知识库没有把第三方下载站或无法确认来源的图纸标记成“原厂图”。
