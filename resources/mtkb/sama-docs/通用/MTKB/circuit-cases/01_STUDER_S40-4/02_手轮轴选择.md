# STUDER S40-4：手轮 X/C/Z 轴选择

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

## 1. 功能

读取面板手轮选轴输入，生成轴选择记忆、CNC 轴选择输出和手轮指示。

- 案例编号：`CKB-STUDER-002`
- 机床：STUDER/FANUC S40-4
- 网络范围：N00011-N00016
- 实际收录网络：N00011  手轮 (HANDLE X AXIS MEMORY), N00012  手轮 (HANDLE C AXIS MEMORY), N00013  手轮 (HANDLE Z AXIS MEMORY), N00014  手轮 (HANDLE CHOICE X), N00015  手轮 (HANDLE CHOICE Z), N00016  手轮 (HANDLE L.)

## 2. 具体电路图（PMC 地址级逻辑）

### N00011  手轮 (HANDLE X AXIS MEMORY)

**作用：** 条件：[手轮 (MPG_X_AXIS)]且非[手轮 (MPG_C_AXIS)]且非[手轮 (MPG_Z_AXIS)]；动作：输出[手轮 (HANDLE X AXIS MEMORY)]。

| 序号 | 指令 | 地址 | 含义 |
|------|------|------|------|
| 1 | 读入常开 | X7.3 | 手轮 (MPG_X_AXIS) |
| 2 | 串联常闭 | X7.6 | 手轮 (MPG_C_AXIS) |
| 3 | 串联常闭 | X7.5 | 手轮 (MPG_Z_AXIS) |
| 4 | 输出 | R25.0 | 手轮 (HANDLE X AXIS MEMORY) |

### N00012  手轮 (HANDLE C AXIS MEMORY)

**作用：** 条件：非[手轮 (MPG_C_AXIS)]且非[手轮 (MPG_X_AXIS)]且[手轮 (MPG_Z_AXIS)]且非[AUTOMATIC OPERATION]；动作：输出[手轮 (HANDLE C AXIS MEMORY)]。

| 3 | 串联常开 | X7.5 | 手轮 (MPG_Z_AXIS) |

## 4. 故障诊断与核对点

- 现有资料指出 Z/C 符号名可能与真实按键互换，必须按地址和实测核对。
- 同时按下多个选轴键时检查互斥是否成立。
- 检查自动运行 F0.7 对 C/Z 选择记忆的抑制。
