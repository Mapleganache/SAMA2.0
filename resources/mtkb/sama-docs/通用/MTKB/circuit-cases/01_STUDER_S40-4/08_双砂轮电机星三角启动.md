# STUDER S40-4：内外砂轮电机星三角启动

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

CONFIRM, N00103  启动 (WH 2 .START CO), N00104  启动 (WH 2.START PL), N00105  启动 (WH 2.START), N00106  WH 2 MOTOR, N00107  WH 2 ST DELAY, N00108  WH2 MOTOR STAT, N00109  WH2 MOTOR DELTA, N00110  WH2 MOTOR L, N00112  IN.WH.CONFIRM, N00113  启动 (WH1.START CO), N00114  启动 (WH 1.START PL), N00115  启动 (WH1.START), N00116  WH1. ## 3. 文字化电路图

```text
启动许可 → 启动脉冲 → 主接触器+星形接触器 → 延时 → 星形断开 → 三角接触器 → 电机运行反馈。
```

启动许可 → 启动脉冲 → 主接触器+星形接触器 → 延时 → 星形断开 → 三角接触器 → 电机运行反馈。

## 4. 故障诊断与核对点

- 主、星、三角接触器必须具有电气和机械互锁。
- 核对切换延时、电机铭牌和过载保护整定。
- 禁止仅凭 PMC 地址确定接触器线圈电压和端子号。
