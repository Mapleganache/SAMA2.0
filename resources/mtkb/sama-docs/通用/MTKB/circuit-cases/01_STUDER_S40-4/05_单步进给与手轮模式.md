# STUDER S40-4：单步进给、增量与手轮模式

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

## 1. 功能

生成单次进给脉冲、Z 轴增量倍率及手轮模式状态。

- 案例编号：`CKB-STUDER-005`
- 机床：STUDER/FANUC S40-4
- 网络范围：N00033-N00047
- 实际收录网络：N00033  FEED SINGLE ONE PULSE, N00034  SINGLE FEED SIGNAL RISING EDGE, N00035  FEED SINGLE ONE PULSE, N00036  Z OVERRIVE AUX1, N00037  SUB 8, N00038  CHOP1, N00039  CHOP2, N00040  CHOP4, N00041  CHOP8, N00042  启动 (Z CHOP START 3), N00043  Z CHOP G, N00044  INC 1, N00045  INC 100, N00046  HS1IA, N00047  手轮 (MPG MODE)

## 4. 故障诊断与核对点

- 检查边沿脉冲宽度，避免一次按键产生多次进给。
- 核对 CHOP1/2/4/8 和实际增量档位。
- 确认手轮模式不会在自动循环中误保持。
