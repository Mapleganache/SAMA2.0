## 机床智能体知识库

本知识库用于机床维修、控制系统、前端画面和工程案例资料管理。

## 主分类路径

具体机床资料按以下顺序分类：

`机床大类 → 机床子类 → 品牌 → 机型 → 原理/实例 → 技术种类 → 资料形态`

通用控制系统资料按以下顺序分类：

`通用技术与控制平台 → 技术种类 → 厂商 → 产品或系统 → 资料主题`

## 基本规则

1. FANUC CNC、PMC、PICTURE 等跨机床通用资料放入 `01_通用技术与控制平台`。
2. 实际机床的程序、图纸、参数和维修记录放入 `10_磨床` 等具体机床分类。
3. PLC/PMC 与 FP/HMI 必须分开；CNC 参数、伺服主轴、通信资料也应分别标注。
4. 原理、官方手册与实际工程、维修案例分开保存。
5. `.vbp`、`.fp2`、XML、脚本、素材和配置组成的完整工程不得拆散或修改内部文件名。
6. 同一份通用说明书只保存一份，具体机型通过资料索引引用，避免重复副本。
7. 型号或磨床类型不能确认时，进入 `待确认型号` 或 `99_待确认磨床类型`，确认后再迁移。
8. 所有案例使用 `00_知识库规范/统一案例模板.md`；没有的字段保留为空并标记 `未提供`。
9. 梯形图诊断必须将地址与注释/符号联合分析，并记录网络、指令、来源和验证状态；冲突时不得直接下现场结论。
