# 电路案例统一模板

## 1. 功能

说明该电路解决什么问题、在机床流程中的位置以及适用机型。

## 2. 具体电路图

放置原图、页码，或按 LAD 给出网络号、触点类型、地址、功能指令和输出地址。

## 3. 文字化电路图

按“电源/输入 → 条件与互锁 → 中间继电器/控制器 → 输出/负载 → 反馈/报警”描述。

## 4. 故障诊断与核对点

列出测量位置、预期状态、常见故障和验证方法。

## 5. 修改或改造边界

列出必须补齐的型号、图纸、负载、供电、安全和厂家手册数据。不得猜测端子、线径或元件最终定值。

## 6. 来源与验证状态

记录来源、版本、日期、是否与现场逐点核对以及工程审核人。
