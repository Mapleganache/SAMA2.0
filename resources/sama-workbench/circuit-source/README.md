# 电路知识库 v2 使用说明

本目录把原有超长 LAD 文本和 PDF 标题条目重新整理为可检索的功能案例。每个案例固定包含：

1. 功能；
2. 具体电路图或 PMC 地址级逻辑；
3. 文字化电路图；
4. 故障诊断与核对点；
5. 修改/改造边界；
6. 来源与验证状态。

## 分类

- `01_STUDER_S40-4`：STUDER S40-4 / FANUC PMC 功能案例；
- `02_MIKROSA_SASL3-2`：MIKROSA SASL3/2 / FANUC PMC 功能案例；
- `03_FAVRETTO_MC160`：用户提供 MC160 EPLAN PDF 的逐页电路案例；
- `90_工程审查`：现有 LAD 分析报告的结构化工程审查；
- `99_来源与规范`：官网核验、资料边界和案例模板。

## 可信度标签

- “地址级转写”：地址和指令来自现有 LAD 转换资料，但尚未与当前机床逐点校验；
- “图纸转写/归属待核对”：来自 PDF 原图，但图框元数据存在不一致；
- “官网核验”：只证明机型或服务入口存在，不等同于获得该机床序列号的原厂电气图。

任何电路修改均须由具备资质的电气工程师复核，且必须以当前机床序列号图纸、厂家手册和现场测量为准。
