# STUDER S40-4：编辑/自动/JOG/MDI/DNC/回零模式

> 安全边界：本案例用于检索、桌面审核和故障定位，不是可直接照抄的现场接线施工图。端子、线径、保护器件和元件定值必须按当前机床序列号图纸及厂家手册复核。

## 1. 功能

把面板模式选择转换为 PMC 辅助状态，并形成自动、点动、MDI、DNC 和回零条件。

- 案例编号：`CKB-STUDER-004`
- 机床：STUDER/FANUC S40-4
- 网络范围：N00020-N00031
- 实际收录网络：N00020  模式 (EDIT MODE AUX), N00021  模式 (AUTO MODE AUX), N00022  模式 (JOG MODE AUX), N00023  模式 (MDI MODE AUX), N00024  回零 (REF MODE AUX), N00025  模式 (DNC MODE AUX), N00026  条件：模式 (EDIT MODE AUX), N00027  条件：模式 (EDIT MODE AUX), N00028  条件：模式 (JOG MODE AUX), N00029  手轮 (AUTO HANDLE), N00030  条件：回零 (REF MODE AUX), N00031  DNC1
