## A-H01｜LEVEL1 急停联锁过简

### 位置

| 项 | 内容 |
|----|------|
| 程序 | LEVEL1 第一级（高速扫描） |
| 网络 | **N00001** NC侧急停 |
| 说明书 | **538 ~ 552 行** |
| 关键 | 输入 `X8.4`；输出 `G8.4`、`G8.0`、`G108.0/1/2`、`G130.0/1/2` |

### 现有逻辑

只要 `X8.4` 为通，就同时：

- 写 NC 急停 `G8.4`
- 写全轴联锁 `G8.0`
- 取反写 X/Z/C 机床锁 `G108.*`
- 写 X/Z/C 轴联锁 `G130.*`

LEVEL1 里**没有**其它输入（门、气压、过载、超程都不进这一网）。

### 问题是什么

高速级本应放「必须立刻停轴」的条件。现在只有急停一个点；其它危险条件最多在 P2/P6，扫描更慢，且多数还不撤 `*ESP/*IT`。

### 会造成什么

门开、气压掉、电机过载等时，轴可能不会像急停那样立刻被 LEVEL1 锁住，存在停得慢、停不全的风险。

### 怎么改 / 改成什么样

1. 做风险评估：哪些条件必须进 LEVEL1 或硬件安全回路。  
2. 建议至少：过载、关键压力丢失、安全门打开 → 能撤 `G8.4` 或伺服使能。  
3. **目标形态（示意）：**

```
LEVEL1：
  (X8.4急停 为安全态) 且 (门关) 且 (无A类压力/过载故障)
  → 写 G8.4 / G8.0 / G130.* …
提示类报警仍放 P6，不要全塞 LEVEL1。
```

## A-H02｜C 轴超程被常1一直顶着

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P1 |
| 网络 | **N00019** |
| 说明书 | **734 ~ 742 行** |
| 地址 | `R9091.1` → `G114.2`、`G116.2` |

### 现有逻辑

`R9091.1`（常1）一通，就同时写 C 轴正、负超程信号。没有限位开关 X。

### 问题是什么

FANUC 的 `*+L/*-L` 多为负逻辑：为 1 表示「没超程 / 允许」。常1一直写 1 ≈ **PMC 永远不报 C 超程**。

### 会造成什么

若机械上有 C 限位却没进 PMC，撞限位时 CNC 侧可能收不到超程；若本来就没有硬件限位，程序里却看不出「故意不监控」。

### 怎么改 / 改成什么样

**方案 A（有硬件限位）：** 仿 X/Z，用限位开关分写正负。

```
目标：
  C+限位 → 只写 G114.2
  C-限位 → 只写 G116.2
  禁止用 R9091.1 无条件写出
```

**方案 B（确认无硬件限位）：** 删除本网或改为文档声明「靠软限位/挡块」；不要留常1假保护。

## A-H03｜JOG 判定过宽，和超程旁路抢同一个模式码

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P1 + P6 |
| 网络 | **N00022**（JOG）、**N00296**（旁路） |
| 说明书 | N00022：**766 ~ 779 行**；N00296：**4354 ~ 4363 行** |
| 地址 | 模式开关 `X3.0/X3.1/X3.2`；`R804.2`；`A0.0` |

### 现有逻辑

**N00022：** 两支路相或：

- 支路1：`¬X3.0 ∧ X3.1 ∧ ¬X3.2`（码 010）
- 支路2：`¬X3.0 ∧ X3.1 ∧ X3.2`（码 011）  
→ 结果等于：`¬X3.0 ∧ X3.1` → 写 `R804.2`（当 JOG）

**N00296：** `¬X3.0 ∧ X3.1 ∧ X3.2`（码 011）→ 写 `A0.0`（超程旁路）

### 问题是什么

拨到 **011** 时：一边认为是 JOG，一边打开超程旁路。两种用途挤在同一模式码上。

### 会造成什么

操作者以为在普通点动，实际超程保护可能已放开（还要结合 A-H04），危险且不好察觉。

### 怎么改 / 改成什么样

```
【改 N00022】删掉第二支路，只保留：
  ¬X3.0 ∧ X3.1 ∧ ¬X3.2  →  R804.2
  （仅 010 = JOG）

【改 N00296】011 专用于服务旁路，并加：
  - 声光提示
  - 限制快速倍率
  - 不要再让 R804.2 为真
```

验收：010 只能 JOG；011 必须有旁路提示且不能当普通 JOG。

## A-H04｜X/Z 超程可被 A0.0 旁路放行

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P1 + P6 |
| 网络 | **N00017**、**N00018**、**N00296** |
| 说明书 | N00017：**704 ~ 717**；N00018：**719 ~ 732**；N00296：**4354 ~ 4363** |
| 地址 | X0.3/0.4、X0.5/0.6、`A0.0`、`G114/G116` |

### 现有逻辑（以 X 为例 N00017）

两条路相或后写超程 G：

1. 正常：`X0.3` 且 `X0.4`  
2. 旁路：区域 `X0.4` 断开时，若 `A0.0` 为通，仍可参与写出  

且同一结果**同时**写 `G116.0` 和 `G114.0`（正负一起）。

### 问题是什么

1. `A0.0` 只要被 N00296 置上，就能参与放开 OT。  
2. 正负同写，CNC 分不清方向。

### 会造成什么

模式拨到旁路码后，X/Z 软件超程可能失效；报警也分不清撞的是哪一侧。

### 怎么改 / 改成什么样

```
【旁路】
  - 不要用普通模式 011 轻易置 A0.0
  - 改为：钥匙开关或独立 K + 限时 + 只允许反向退出超程区

【正负分写】（示意，以电气图 NC/NO 为准）
  X-限位 → 只写 G116.0
  X+限位 → 只写 G114.0
  Z 同理分写 G114.1 / G116.1
```

## A-H05｜K0.0 旁路气液，仍可就绪并开伺服

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P2、P6 |
| 网络 | **N00094**、**N00096**、**N00301~N00303**、**N00305** |
| 说明书 | N00094：**1868 ~ 1879**；N00096：**1881 ~ 1890**；报警约 **4404 ~ 4459** |
| 地址 | `K0.0`、`X2.0`、`X2.2`、`R710.0`、`Y0.0`/`Y4.0`/`Y4.2` |

### 现有逻辑

```
R710.0 = 就绪自保链 ∧ ( (X2.0气压 ∧ X2.2液压)  ∨  K0.0 )
Y0.0 伺服 / Y4.0 液压泵 / Y4.2 冷却泵  ← 直接跟 R710.0
气/液/润滑报警条件里也有 ¬K0.0，K0.0=1 时可屏蔽报警
```

### 问题是什么

保持继电器 `K0.0=1` 时，没气没液压也能「机床就绪」并开伺服和泵。

### 会造成什么

无压力仍可运行；掉电后 K 仍保持，下次上电可能带着旁路开机。

### 怎么改 / 改成什么样

```
【就绪】
  R710.0 = … ∧ (X2.0 ∧ X2.2)     ← 去掉 ∨ K0.0
  或：旁路时只允许点动调试，禁止自动与砂轮

【K0.0 若保留】
  - 钥匙开关置位
  - 限时自动清除
  - 强制 A 类报文 / 灯
  - 旁路时禁止 Cycle Start、禁止砂轮启动
```

## A-H06｜K2.0 旁路套筒前位，多处仍可转 C

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P3 |
| 网络 | **N00149、N00154、N00158、N00160、N00161、N00162** |
| 说明书 | 约 **2446 ~ 2648 行**（多处出现 `K2.0`） |
| 地址 | `X4.7`（前位）、`K2.0`；`X4.6`（后位）全书无读写 |

### 现有逻辑

多处条件为：`(X4.7 通) 或 (K2.0 通)` 才允许相关 C 轴旋转/M03/M04 等逻辑继续。

### 问题是什么

`K2.0=1` 时不要求套筒前位；后位 `X4.6` 根本没进程序，无法做前后互锁。

### 会造成什么

### 怎么改 / 改成什么样

```
【正常运行】
  必须 X4.7=1，禁止用 K2.0 旁路
  建议增加：X4.6 参与「前后非法状态」报警

【维修旁路若保留】
  仅钥匙模式 + 限时 + 禁止自动 M03/M04
```

## A-H08｜砂轮确认被常1并掉（形同虚设）

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P2 |
| 网络 | **N00103**、**N00113** |
| 说明书 | N00103：**1935 ~ 1945**；N00113：**2041 ~ 2051** |
| 地址 | `R710.0`、`K0.1`/`K0.2`、`R0.0`（常1，N00087 产生） |

### 现有逻辑

```
N00103: R860.2 = R710.0 ∧ (K0.1 ∨ R0.0)
N00113: R861.2 = R710.0 ∧ (K0.2 ∨ R0.0)
```

`R0.0` 恒为 1 → 括号永远为真 → 确认位毫无作用。

### 问题是什么

写了「要确认才启动」，又并了永远为真的常1，确认被废掉。

### 会造成什么

未确认砂轮位置也可能满足启动条件（后续还看按钮脉冲等，但确认互锁已失效）。

### 怎么改 / 改成什么样

```
【删除并联常开 R0.0】

改后：
  N00103: R860.2 = R710.0 ∧ K0.1
  N00113: R861.2 = R710.0 ∧ K0.2
```

验收：K0.1/K0.2 未置位时，不能出启动条件位。

## A-H09｜内外砂轮确认互相拆台

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P2 |
| 网络 | **N00102**、**N00112** |
| 说明书 | N00102：**1924 ~ 1933**；N00112：**2030 ~ 2039** |
| 地址 | `X1.4`、`X1.3`、`K0.1`、`K0.2` |

### 现有逻辑

```
N00102: (X1.4 ∨ K0.1) → SET K0.1，RST K0.2     （选外，清内）
N00112: (X1.3 ∨ K0.1) → SET K0.2，RST K0.1     （条件里挂了外确认！）
```

### 问题是什么

刚在 N00102 置好 `K0.1`，扫到 N00112 时因为 `∨ K0.1` 为真，又会 SET 内、RST 外。两个确认在同一扫描里打架。

### 会造成什么

确认状态抖动或总被改成内砂轮；后续启动条件不可靠。

### 怎么改 / 改成什么样

```
【N00102 保持】
  (X1.4 ∨ K0.1) → SET K0.1，RST K0.2

【N00112 改为】
  (X1.3 ∨ K0.2) → SET K0.2，RST K0.1
  ↑ 自保用自己的 K0.2，不要 OR K0.1
```

## A-H10｜报警复位键同时触发 NC Reset & Rewind

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P1 |
| 网络 | **N00069** |
| 说明书 | **1471 ~ 1482 行** |
| 地址 | `X8.0` → `G8.7` + `G8.6`（还与 M02/M30/E-BACK 并联） |

### 现有逻辑

按下 `X8.0`，同时输出外部复位和复位并倒带。

### 问题是什么

「清报警灯」和「倒带程序」绑在同一键上；物理危险条件并不会因这一按而消失。

### 会造成什么

操作者以为只是消报警，实际程序状态被清掉；危险条件仍在时可能继续操作。

### 怎么改 / 改成什么样

```
【拆开】
  报警复位键 X8.0 → 只清 PMC 报警辅助 / 灯
  NC Reset / Rewind → 单独键或单独条件

【联锁】
  A 类报警未消失时，禁止写 G8.6（Rewind）
  复位后不自动恢复 Y0.0
```

## C01｜手轮符号名写歪了（原误判为 H02/H03 逻辑交叉）

### 位置

| 项 | 内容 |
|----|------|
| 程序 | P1 |
| 网络 | N00011 ~ N00015 |
| 说明书 | **637 ~ 692 行** |
| 地址 | `X7.3/5/6`、`R25.0/1/2`、`G18.0/1` |

### 地址真实链路（没有交叉）

```
X7.3 → R25.0 → G18 = 10（常见第1轴）
X7.5 → R25.2 → G18 = 01（常见第2轴）
X7.6 → R25.1 → G18 = 11（常见第3轴）
```

### 问题是什么（注释层面）

符号把 `R25.2` 叫成「C 记忆」、`R25.1` 叫成「Z 记忆」，容易让人以为按键和记忆交叉。  
**地址运算本身是顺的**，现场手轮往往能动对。

### 会造成什么

后人按符号名「修正交叉」，对调 N00012/13，反而把好用的链改坏，选错轴。

### 怎么改 / 改成什么样

**只改符号表/注释，不要改这两级布尔（除非电气图证明按键接反）。**

建议命名与地址一致，例如：

| 地址 | 建议符号名 |
|------|------------|
| R25.0 | HANDLE_MEM_AXIS1 或 HANDLE_X_MEM |
| R25.2 | HANDLE_MEM_AXIS2 或 HANDLE_Z_MEM（因 X7.5→R25.2→01） |
| R25.1 | HANDLE_MEM_AXIS3 或 HANDLE_C_MEM（因 X7.6→R25.1→11） |

说明书「作用」同步改成与地址一致，避免再写「非 C 而 Z → C 记忆」这种误导句。
