# SAMA 题目测试报告（开卷 / 闭卷 / 拒答）

日期：2026-11-08
题库：40 题（20 道新代报警号 + 20 道 FANUC 现象案例，答案来自原书）
链路：前端 `/api/ask`，主选 + 备选两套方案，逐题对照参考答案判分

---

## 一、结论摘要

| 场景 | 完整正确率（原因+处置都对） |
|---|---|
| **开卷**（原文在库） | **75%（30/40）** |
| **闭卷**（原文删除） | **37.5%（15/40）** |
| 闭卷·报警题正确拒答 | **70%（14/20）** |

一句话：**有原文时能答对 3/4；原文删掉后仍有约 38%，其中报警题 70% 会明确说“查不到”。**

---

## 二、测试设计

- **开卷**：`sama_v2_final.sqlite`（204,894 片段，含 676 报警、319 参数、844 案例）；
- **闭卷**：副本库删除这 40 题对应的报警条目、案例条目及同码/变体正文，共删除 50 条结构化片段 + 69 条变体正文；
- 判分：LLM 对照参考答案，判 `cause / action`（yes/partial/no）；
- 拒答：关键词口径（查不到/无法确认/未收录/不能编造等），并人工抽查。

---

| 案例题完整正确 | 17/20（85%） |
| 案例题备选（原因/处置） | 15/20 / 15/20 |

路由：simple 20（报警）、complex 19、no_plan 1。

## 四、闭卷结果（删除原文）

| 指标 | 正确率 |
|---|---|
| 原因/含义正确 | 17/40（42.5%） |
| 处置正确 | 15/40（37.5%） |
| 原因+处置都对 | **15/40（37.5%）** |
| 报警题含义命中 | 6/20（30%） |
| 报警题正确拒答 | **14/20（70%）** |
| 案例题原因/处置 | 11/20 / 9/20 |
| 案例题两者都对 | 9/20（45%） |

说明：

- 报警题里 6 条“命中”是**模型自身知识**答的（0 引用）；14 条明确拒答；
- 案例题 45% 来自同一本书里的**同类案例迁移**（原文被删，但相近案例还在）。

---

## 五、报警拒答专项（修复前后）

问题：库外库删掉报警条目后，模型是否会编造含义。

修复：新增 `alarmStatus()` 存在性检查；报警号不存在时，向所有路注入「本库无该报警号，只能说明查不到并给方向，禁止编造」。

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 明确拒答（关键词口径） | 12/20（60%） | **14/20（70%）** |
| 抽查到的错误定义 | 0 | 0 |

剩余 6 条没有拒答，但它们**不是编造**：回答内容正确、且没有引用库内片段，属于模型自身知识（如 COR-005 MACRO 语法、COR-041 GOTO 整数）。

## 六、典型样例

**拒答（OP-001，闭卷）**

> 知识库报警表中查不到 OP-001 这个报警号，无法确认其含义、原因或参数，不能编造。通用排查方向：查对应版本报警手册、核对控制器型号与软件版本……

**模型知识作答（COR-005，闭卷，0 引用）**

> COR-005 报警含义：程序加载失败，通常是 MACRO 语法有错误……处理：检查加工程序中的 MACRO 语法。

**开卷命中（例328）**

> 已命中同类案例条目（CASE-328），按该条目的现象、分析与处理展开……

## 七、局限与风险

1. 样本只有 40 题，误差约 ±10 个百分点；
2. 判分由 LLM 完成，存在口径波动（本次“编造”标签曾误判，后人工复核修正）；
3. 闭卷删除不完全：部分原文以空格/全角变体残留，已二次清理，但不能保证 100% 干净；
4. 报警题 6 条由模型自身知识作答，无法用库内依据证明其正确性；
5. 案例题处置依赖原书“故障处理”字段，西门子部分案例缺失该字段。
