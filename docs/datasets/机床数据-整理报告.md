## 4. 处理流程

1. 旧版 `.doc` 用本机 Word 转 `.docx`（15 个）；
2. PDF 有文本层按页抽取，扫描件按 150 dpi 渲染 + RapidOCR；
3. OpenCC 繁转简（新代手册大量繁体）；
4. 去页眉页脚、页码、目录行；按标题层级切 500–800 字；
5. 分类：`machine_type` / `domain` / `subsystems_json`；
6. 灌入 `sama_ext.sqlite`，表结构从主库克隆（含 `release_meta`、`full_term_stats`）；
7. 倒排用与 SAMA 相同的**字 bigram**，BM25 词频表同步生成。

## 8. 下一步（迁移）

合并脚本已就绪：

```powershell
node D:\SAMA\audit\ingest\merge_ext.mjs `
  --ext=D:\SAMA-data\corpus\机床数据\sama_ext.sqlite `
  --main=D:\SAMA\SAMA\sama2.0\data\sama_full.sqlite `
  --out=D:\SAMA-data\corpus\机床数据\sama_merged.sqlite `
  --allow=1
```

- 默认**不覆盖**原库，输出 `sama_merged.sqlite`；
- `--allow=1` 会放开外部资料准入（建议先跑评测再决定）；
- 合并后需重建词图：`node scripts/build-term-graph.mjs`（指纹会变）；
- 建议先合并到副本、跑 20 条留出评测，再替换正式库。
