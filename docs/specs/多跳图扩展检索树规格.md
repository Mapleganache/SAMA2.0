# 多跳图扩展检索树规格（仓库内落地版）

对照桌面原稿 `问题以及新的方案2/多跳图扩展检索树/多跳图扩展检索树规格.md`。原稿与文献 PDF 不在本仓库；这里写的是当前代码实际遵守的规格。

## 目标

磨床问句常停在表面词。问「齿面粗糙度」，有用段落往往写「导轨爬行」「油品抗爬」。五路若只改成稿温度、第 0 次检索仍撞同一批片段，后面的评分只是在同一盆地里比稿。

要同时做到：

1. 分温作用在第 0 步入口查询，而不是只改 ReAct 提议温度。
2. 在词 / 概念图上做 beam 扩展，用折扣净收益 $\Delta G$ 决定还要不要再跳，而不是写死 $H_{\max}=2$。

出处核对、型号 / 油压硬拒绝、ReAct 工具循环不在本规格范围内，保持原行为。

## 第 0 步入口

对用户输入 $x$ 构造候选池：原句、桥接改写、机理槽、抗热相关改写。每条候选有 prior；无外部嵌入时用规则分与词法重叠。

五路温度 $\tau=(0.35,0.5,0.85,1.0,0.95)$。默认 Softmax：

$$
P_i(q)=\frac{\exp(\mathrm{prior}(q)/\tau_i)}{\sum_{q'}\exp(\mathrm{prior}(q')/\tau_i)}
$$

$\tau\le 0.4$ 的低温路取 prior 的 argmax（通常是原句）。跨路 Jaccard 过高则重抽，最多 3 次。备选 MMR。同一 $\tau_i$ 传给该路 `tauProp`。

## 树上扩展

路径 $\pi$ 维护词集合 $T$、片段 $D$、相关分 $S$、累计回报 $G$。候选来自：

- 手写桥接 `BRIDGES`
- 离线共现图（`full_postings` 上诊断词的 PMI 边，文件 `sama-sqlite/term-graph.json`）
- 当前命中片段抽出的机理 / 新词

宽度 $K\in\{3,5,7\}$，默认 3。词集合 Jaccard $>0.8$ 的近重复路径只留分高的一条。

## 打分

$$
s(x,T)=\alpha\,s_{\mathrm{vec}}+(1-\alpha)\,s_{\mathrm{lex}}^{\mathrm{norm}}
$$

- $s_{\mathrm{lex}}^{\mathrm{norm}}$：命中 BM25 原始分经 $r/(r+5)$ 压到 $(0,1)$。
- $s_{\mathrm{vec}}$ 默认是词频稀疏向量余弦（本地、同步、无外网模型）。`SAMA2_EMBED=jaccard` 可退回集合重叠。接 BGE-M3 等服务时替换 `resolveScoreVec`，停机公式不变。
- $\alpha$ 默认 $0.5$。

## 停机

$$
G=\sum_n\bigl(\gamma^{n-1}S_n-c_n\bigr),\qquad
\Delta G_n=\gamma^{n-1}(S_n-S_{n-1})_{+}-c_n
$$

主停机：$\Delta G_n\le 0$。默认 $\gamma=0.6$，$\lambda_{\mathrm{hop}}=0.15$。保险丝：检索次数 12、跳数 16、无新文档、查询 Jaccard $\ge 0.85$。

返回 $G$ 最大路径上的片段（去重后最多 4 条），写入该路第 0 步观察。只返回带 `sqlite_*` id 的片段。

## 明确不做

- 不把共现边或哈希向量当成现场已确认原因。
- 不绕过出处核对去交付扭矩、间隙、压力。
- 不把文献 PDF 打进仓库。
