## 磨床拉分改动

1. `agent.mjs` §10：强制成品直径、轴向覆盖、**锥度禁止恒直径横磨**（须 `G01` 同时变 X/Z，两端出现 `d_large`/`d_small`）
2. `compare-run.mjs`：外圆磨认 `Z0→-L`，无心通磨认 `Z0→+L`；锥度两端直径齐全才满分
3. 复跑 G04：程序现含 `G01 X40 Z0` → `G01 X34 Z-60` 锥面

## 评分修订要点

1. 孔位集合匹配（先解析同行 XY，再记孔）  
2. 铣削比切削深度，不比 Z50 vs Z100 安全高度  
3. 车床比直径集合 + 轮廓点，G71 的 W/U 增量展开  
4. 磨床按目标尺寸是否出现在程序中给分
