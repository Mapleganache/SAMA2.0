# SAMA 前端重构说明

日期：2026-11-15  
目标：去掉 G 代码、磨床结构、电路图三个占位模块，只保留现有诊断功能，并把界面重做成“诊断工作台”。

---

## 一、改了什么

### 删除

- `G 代码` tab；
- `磨床结构` tab；
- `电路图` tab；
- 对应的占位页和切换逻辑。

### 保留并强化

- 诊断对话；
- 简单/复杂/需补充/无方案四类路线；
- 假设作答提示；
- 补充信息（need_info）会话；
- 候选方案、五维评分、加权总分；
- 流程 / 各路轨迹 / 评分检查表；
- API Key / Base URL / 模型 / 判分模型 / maxStep 设置；
- 联网兜底、强制五路。

### 新布局

```
左侧：品牌、新对话、最近问题、设置/状态
中间：对话流 + 输入框
右侧：诊断详情（判定、识别信息、候选方案、流程）
```

- 宽屏三栏；
- 1200px 以下详情面板悬浮；
- 820px 以下单栏，详情默认隐藏，顶栏“详情”按钮打开；
- 支持浅色/深色主题；
- 最近问题保存在浏览器 localStorage；
- 回答 Markdown 渲染（标题、列表、表格、代码、引用）；
- 引用 id 自动变成 chip。

## 二、视觉原则

参考了 Linear 的设计语言与主流 AI 聊天界面（Claude / Lumen 类）的共性：

- [Linear 风格配方](https://github.com/ConardLi/garden-skills/blob/main/skills/web-design-engineer/references/style-recipes/linear.md)：细线、单一强调色、克制的圆角、150ms 级动效；
- [Lumen AI Chat UI Kit](https://www.ui8.net/docoruiux/products/lumen--ai-chat-ui-kit--design-system)：对话区留白、弱化气泡、侧栏收敛。

落地为：

| 项 | 做法 |
|---|---|
| 底色 | 暖白 `#f6f4ef`，不是冷灰/蓝黑 |
| 侧栏 | 浅暖灰 `#efede6`，不再用深色渐变 + 发光 |
| 强调色 | 低饱和鼠尾草绿 `#4e6b5f`，只用于按钮、关键标题 |
| 边框 | 1px 暖灰细线，代替重阴影 |
| 圆角 | 小控件 7–9px，卡片 10–12px，不超过 14px |
| 阴影 | 仅输入框/弹窗保留极浅阴影，无彩色光晕 |
| 消息 | 用户浅灰气泡；助手不套气泡，直接排版 |
| 字体 | 14.5px / 1.62，标题 -0.03em 字距 |
| 动效 | 消息入场 180ms `cubic-bezier(.22,1,.36,1)`；hover 140ms；支持 `prefers-reduced-motion` |

没有引入 Tailwind/React 等构建依赖：本地离线运行更稳，也不需要额外安装。

## 四、接口

沿用原接口：

```
POST /api/ask
{
  userText, apiKey, baseUrl, model, judgeModel,
  maxStep, forceMultiAgent, allowWeb, webAuto, session
}
```

新增：

```
GET /api/health
→ { ok: true, configured: boolean, model: string }
```

前端用 `/api/health` 判断“服务端是否已配置 Key”：

- 本地填了 Key：显示模型名，正常发送；
- 本地没填、服务端 `settings.json`/环境变量有 Key：允许发送；
- 都没有：打开设置并提示填写。

## 六、启动

```powershell
cd D:\SAMA\SAMA\sama2.0
$env:SAMA2_PORT='3920'
node server.mjs
```

打开 `http://127.0.0.1:3920/`。

首次使用在“设置”里填 API Key；也可以把 Key 放到 `sama2.0/settings.json` 或环境变量 `SAMA2_API_KEY`，前端会识别为“服务端配置”。
