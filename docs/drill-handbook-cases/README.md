# 钻削扩削铰削 · 从手册抽出的可用案例

来源：《机械加工工艺手册》单行本《钻削、扩削、铰削加工》（王先逵，2008）。  
压缩包本身是 OCR 清洗版，**不是**完整 CAM 数据包。下面只收录「零件 + 尺寸 + 机床 +（有则）程序」能配上的实例。

图纸在 `drawings/`，程序在 `nc/`。带 `_手册原文` 的是书上原句；带 `_FANUC` 的是按同一尺寸改写成常见 FANUC 格式，下机床前要按本机循环核对。

## 1. 直摇臂两端孔（图 3.6-1）

- 机床：**Z3025 摇臂钻床**
- 零件：直摇臂，孔距 **120 mm**
- 尺寸：大端 φ25(+0.045/0)，Ra 6.3，倒角 C1；小端 φ12(+0.07/0)，Ra 6.3，倒角 C0.5
- 工序：钻 φ22 → 倒角 2.5×45° → 扩 φ24.6 → 铰 φ25 → 钻 φ11.6 → 倒角 0.7×45° → 铰 φ12
- 用量（书）：钻 φ22 时 f=0.28 mm/r，n=272 r/min
- 程序：无（普通摇臂钻，不是数控程序）
- 图纸：`drawings/fig3.6-1_直摇臂_Z3025.jpg`

## 2. 弯曲拉臂多孔（图 3.6-2）

- 机床：**六工位组合机床**（书未给数控型号）
- 零件：弯曲拉臂，年产 14 万
- 尺寸：大端钻 φ23 倒角 2.3×45°，扩 φ24.6 Ra12.5，铰 φ25(+0.045/0) Ra6.3；小端钻 φ10 倒角 1.5×45°，扩 φ11.7，铰 φ12(+0.07/0)；另钻/铰大端二联孔 φ7.6 → φ8(+0.07/0)
- 程序：无
- 图纸：`drawings/fig3.6-2_弯曲拉臂.jpg`

## 3. 泵体阀孔（图 3.6-5）

- 机床：**X5120 加工中心**
- 零件：泵体阀孔
- 尺寸：倒角保证大端 φ16；钻 φ12.5 深 15；攻 **M14×1.5-6H** 深 10；钻 φ3 距端面 20；钻 **φ0.6 通孔**
- 用量：n=550 / 575 / 195 / 2000 / 3000 r/min
- 程序：书上只有工步表，没有 NC
- 图纸：`drawings/fig3.6-5_泵体阀孔_X5120.jpg`

## 4. 四孔钻孔（图 3.6-6）— 有程序

- 机床：数控立式钻床 / 钻削中心（书未写型号）
- 零件：平板 4×φ8 孔，深 18
- 尺寸：原点左下；孔心圆中心 X200 Y200，半径 100；首孔 X200 Y300，间隔 45°；安全面 Z100，R 面 Z2；钻尖 2.4 → 进给深 22.4；S=600
- 程序：
  - `nc/O3606_四孔G81_手册原文.nc`
  - `nc/O3606_四孔G81_FANUC.nc`

## 5. 两孔深孔（图 3.6-7）— 有程序

- 机床：同上，未写型号
- 零件：2 孔，深 58
- 尺寸：孔位 X30 Y30 与 X400 Y400；分 3 段 peck，每段 20
- 程序：
  - `nc/O3607_两孔G83_手册原文.nc`
  - `nc/O3607_两孔G83_FANUC.nc`

## 6. 四螺纹孔（图 3.6-8）— 有程序

- 机床：同上，未写型号
- 零件：4 螺纹孔，深 18
- 尺寸：矩形 X30/400 × Y30/400；I=-20，螺距 K=1.5，S=500，F=350
- 程序：
  - `nc/O3608_四螺纹孔G84_手册原文.nc`
  - `nc/O3608_四螺纹孔G84_FANUC.nc`

## 7. HT200 通孔钻扩铰（图 3.4-1）

- 机床：**Z535 立式钻床**
- 零件：HT200，210 HBS
- 尺寸：成品孔 **φ25 IT8，Ra 3.2**；孔深按书 l=106（相对钻头 φ22）
- 用量：钻 φ22 f=0.43 n=195；扩 φ24.7 f=0.57 n=275；铰 f=1.6 n=100
- 程序：无
- 图纸：`drawings/fig3.4-1_HT200孔_Z535.jpg`

## 8. 主轴内孔深孔（图 3.6-9）

- 机床：**C630 车床改装深孔机床**
- 零件：45 钢主轴，模锻正火，年产 3000
- 尺寸：喷射钻 ap=19 mm
- 用量：f=0.17 mm/r，n=750 r/min，v=89.5 m/min
- 程序：无
- 图纸：`drawings/fig3.6-9_主轴内孔_C630.jpg`

## 9. 曲轴油孔（图 3.6-10）

- 机床：**三工位组合机床**（定转矩，防钻头折断）
- 零件：45 钢曲轴，年产 10 万
- 尺寸：连杆轴颈中部 SR4 球坑深 4.5，倒角 0.7×45°，Ra 12.5；斜油孔 **φ4 通孔**，Ra 12.5
- 程序：无
- 图纸：`drawings/fig3.6-10_曲轴油孔.jpg`
