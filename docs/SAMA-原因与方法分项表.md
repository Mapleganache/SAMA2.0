## 1. 判分规则

- **原因对**：主方向与近邻机理同类（导轨润滑 / 主轴供油 / 案例或报警表给出的原因），不是无出处的通识清单。
- **方法对**：步骤针对该机理或表内排除方法，且没有无出处的确定油压/间隙。
- **方法条件正确**：把金标原因写入用户补充后再跑，只看处置节（本表第三列预留，本轮不跑）。

四格：原因对方法对 / 原因对方法错 / 原因错方法对 / 都错。另记 Top-2 是否有一路原因对。
