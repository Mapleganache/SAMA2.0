## 二、方案 A 细节

### 2.1 允许重复命中

原来：扩展查询 exclude 已见文档后，如果 top-K 为空，候选直接丢弃。
现在：回退成「可以含重复」的结果，不丢候选。

### 2.2 重复的收益

```js
// 第二次命中 +1.0，第三次 +0.5，之后 0
repeatWeight(2) = 1
repeatWeight(3) = 0.5
repeatWeight(4) = 0
```

```js
gain = max(gNew, gRep, ...)     // 有新篇时取新篇相关度
S_n  = max(S_{n-1}, docScore)   // S 不加 η
ΔG   = γ^(n-1) × (gain − λ)
```

### 2.3 后续修正（关键）

| 问题 | 修正前 | 修正后 |
|---|---|---|
| 重复抬高排序分 | #411 的 G 从 0.662 → **1.063**（S 没变） | 重复跳 `delta=0`，G 不再涨 |
| 重复篇不相关 | 换刀题路径漂到「顶尖 / 磨削细长工件」 | 重复篇 < 0.8×种子锚点直接丢 |
| 空转链过长 | 连续 2 跳无新篇才停 | 默认 1 跳无新篇即停 |

修正后实测：

| 问题 | 修正前 | 修正后 |
|---|---|---|
| 加工中心换刀 | 3 跳（0/0/0 新篇） | **1 跳** |
| #411 报警 | 3 跳（0/0/0 新篇，G=1.063） | **2 跳**（1 篇新文档，G=0.843） |

## 三、方案 B 细节

1. 邻域候选先按**便宜分**做无放回 Softmax 抽样：

```js
hopTermScore = 0.55×词面相关 + 0.35×PMI + 0.15×(机理词?)
```

2. 只对抽中的边做 BM25 + ΔG，减少无效检索；
3. 温度默认继承该路温度，seed 用 `pathSeed + 1009×hopIndex`，可复现；
4. `rho>0` 时才启用随机 beam（默认关）。

## 六、结论

1. **方案 A/B 的工程目标达成**：重复不再制造假链，2 跳只在有新篇时发生，路径质量提升；
2. **扩表没有提升库外准确率**：48→82 节点、边也合理，但 20 题里 16 题仍只 1 跳，新增邻居没被用上；
3. **库外天花板是“知识不存在”**：换几个邻居词改变不了答案本身；
4. 20 题样本误差约 ±10pp，5→4 属于噪声，不能据此判定扩表有害；
5. 当前瓶颈排序：数据 > 扩展参数（topK/λ）> 词表。
