# SAMA λ=0.10 50 题验证与调参结论

日期：2026-11-14  
范围：真基线 worktree（b05d6e3）× 库外 50 题  
目的：验证 20 题单变量筛出的“λ=0.10 最优”是否真实。

---

## 一、结论

**λ=0.10 没有增益。**

| 配置 | 原因 | 处置 | 任一原因 | 任一处置 |
|---|---:|---:|---:|---:|
| 真基线 | **17/50** | **14/50** | 18/50 | 17/50 |
| 真基线 + λ=0.10 | **17/50** | **14/50** | 19/50 | 14/50 |

配对比较：

```
原因：λ 赢 4、输 4，净胜 0
处置：λ 赢 4、输 4，净胜 0
```

> 20 题上的 8/6（+2/+2）是样本噪声，50 题完全归零。

## 二、背景

### 2.1 为什么用真基线 worktree

当前主代码即使把所有参数回默认，20 题只有 **3/2**；  
真基线代码（b05d6e3 worktree）20 题是 **6/4**、50 题是 **17/14**，能复现历史水平（17/12）。

所以调参必须在 worktree 上做。

### 2.2 20 题单变量结果

基线 6/4，8 组单变量：

| 组 | 原因 | 处置 | 配对净胜（原因/处置） |
|---|---:|---:|---:|
| **λ 0.15→0.10** | **8/20** | **6/20** | **+2 / +2** |
| **topK 3→5** | **8/20** | 5/20 | **+2 / +1** |
| maxStep 8→16 | 7/20 | 6/20 | +1 / +2 |
| 预算 12→24 | 7/20 | 6/20 | +1 / +2 |
| hops 2→3 | 7/20 | 5/20 | +1 / +1 |
| γ 0.6→0.7 | 6/20 | 6/20 | 0 / +2 |
| beam 3→5 | 6/20 | 4/20 | 0 / 0 |
| hops 2→4 | 5/20 | 3/20 | −1 / −1 |

### 2.3 组合结果（已失败）

| 组合 | 原因 | 处置 |
|---|---:|---:|
| λ0.10 + topK5 | 6/20 | 5/20 |
| λ0.10 + topK5 + maxStep16 + 预算24 | 4/20 | 2/20 |

## 四、最重要的教训

### 4.1 20 题只能筛，不能定

本次是典型例子：

```
20 题：8/6，净胜 +2 → 看起来有效
50 题：17/14，净胜 0 → 完全归零
```

20 题的 ±2 波动足以制造假阳性。

### 4.2 参数不可叠加

λ0.10 + topK5 从 8/5 掉到 6/5；  
再加 maxStep16、预算24 掉到 4/2。

说明这些参数存在负交互，不能“把正收益项都加上”。

### 4.3 单变量 + 50 题确认是底线

- 20 题：只用于淘汰明显负收益；
- 50 题：确认是否保留；
- 净胜 ≥3 且配对置信区间不跨 0，才允许上线。

## 五、建议

### 5.1 停止树参数调优

- λ：50 题归零；
- topK=5：20 题 8/5，但同批 λ 已证明是噪声，topK 大概率相同；
- hops/γ/beam/预算：均无稳定收益。

**保留基线：beam3、γ0.6、hops2、λ0.15、预算12、maxStep8。**

### 5.2 下一步转向组件级

不再调树参数，改做：

1. D_pack（开/关）；
2. expand_tree（开/关）；
3. 证据 Judge（影子/正式）；
4. prompt / brief / grounding。

每项单独 50 题配对，确认有正收益再保留。

### 5.3 如果一定要验证 topK=5

用 50 题直接跑，不再用 20 题：

```
真基线 vs 真基线 + topK5
```

如果净胜 <3，直接放弃。
