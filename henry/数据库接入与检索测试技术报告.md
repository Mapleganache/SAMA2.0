# SAMA 2.0 数据库接入与检索测试技术报告

日期：2026-11-02

## 数据库接入

项目已通过 `sama2.0/sama-database.json` 默认启用 SQLite 的 `reference` 模式；`search_knowledge` 和 `search_mtkb` 使用只读本地资料。资料包含机械原文、历史案例和来源信息，检索输出注明适用范围和审核状态。正式批准的维修资料为零，资料中的历史数值和处理方式不能直接当作本机结论。具体配置与数据分发见 [DATABASE.md](../sama2.0/DATABASE.md)。

## 本次代码修改

修复 `grounding.mjs` 中引用校验的前缀误匹配：此前观察仅包含 `sqlite_curated:123` 时，方案中的 `sqlite_curated:12` 可能被误判为已有依据。现在分别提取方案与观察中的完整引用，再进行集合匹配；增加真实引用与伪造前缀的回归测试。保留仓库现有的引用类型和其他校验逻辑。

## 检索测试

测试使用已有的 12 道开发题，默认 `reference` 模式；4 道诊断题排除历史案例。每道需要指定资料的题，只有所有预期 ID 均出现在返回条目中才算完整命中。这是固定 ID 的检索测试，不是语义相关性全面评估或诊断准确率。

| 指标 | 结果 |
| --- | --- |
| 需要指定 ID 的题目完整命中 | 6/9（66.7%） |
| 指定 ID 命中 | 9/13（69.2%） |
| 未完整命中 | D01、D04、E02 |
| 其余 3 道无指定 ID 的边界题 | 均返回限制说明 |

D01 缺少预期的低温油液资料；D04 未返回预期的两条润滑资料；E02 未返回预期资料。未命中指定 ID 不能单独证明其他结果不相关，应结合原文人工审核。

[测试题集](数据库检索测试题集.json)和[逐题原始输出](数据库检索测试结果_20261102.json)随报告提供。检索测试运行于桌面 `sama2.0` 副本，不能直接声称它是本提交最新版的测试结果。数据集为既有开发集，规模小且未经过维修专家认证；结果不能推广为总体数据库准确率。此次没有配置模型 API Key，也没有测试真实模型生成的最终诊断答案。
